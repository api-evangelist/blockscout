# Blockscout (blockscout)

Blockscout is an open-source EVM blockchain explorer covering 1,000+ L1, L2, and L3 EVM chains. Each instance exposes a REST v1 API (legacy), REST v2 API (recommended), GraphQL API, and an Etherscan-compatible API. The hosted Blockscout PRO API at `dev.blockscout.com` provides multi-chain access with credit-based metering.
